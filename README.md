# Hermes Agent Memory Backup

Auto-synced every 2 hours from Hermes Agent persistent memory.

- `MEMORY.md` — Personal notes and environment facts
- `USER.md` — User profile and preferences
- `backups/` — Timestamped local backups (last 30)

Powered by [Hermes Agent](https://github.com/NousResearch/hermes-agent).
